# Security policy

This is a learning and portfolio project; it does not process real user data. Findings are still
welcome.

Report a vulnerability privately with GitHub's **Report a vulnerability** button (Security tab),
not in a public issue. Expect a first answer within a few days.

In scope: the pipeline (`.github/workflows`), the container image, the Terraform stack, the Ansible
role and the sample app. See `docs/threat-model.md` for what the project defends against and what it
does not.
